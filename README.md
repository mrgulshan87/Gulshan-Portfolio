A personal portfolio website showcasing my data analytics projects, skills,
and journey as an aspiring Data Analyst — built with [Lovable](https://lovable.dev)

**Live app**: https://gulshan-kumar-kushwaha.lovable.app

## ✨ What this site includes

- A clean, editorial-style landing page introducing my background and goals
- Project showcase section featuring my data analytics and ML work
- Skills section covering Excel, SQL, Python, Power BI, and GenAI tools
- Resume highlights and education (Postgraduate Program in Data Science &
  Analytics with GenAI, Imarticus Learning)
- Contact and social links (GitHub, LinkedIn)
